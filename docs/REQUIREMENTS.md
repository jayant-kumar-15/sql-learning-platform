# Requirements

## Features

- SQL tutorials (Beginner to Advanced)
- Healthcare database
- Banking database
- SQL playground
- User Sandbox
- Query history
- Admin dashboard
- Settings page

## Authentication Requirements

- User signup
- User login
- Forgot password
- Guest mode (limited access)
- Admin login

## UI Requirements

- Snowflake-like UI
- Dark/light mode
- Responsive design
- Mobile-friendly design

## Tutorial Requirements

- Beginner SQL course
- Intermediate SQL course
- Advanced SQL course
- Real-world examples
- Practice questions
- Query explanations

## SQL Playground Requirements

- Execute SQL queries
- Query history
- Query auto-suggestions (ON/OFF)
- Save queries
- Export query results as CSV
- Import sample SQL files
- Results table
- Multiple tabs like Snowflake

## User Sandbox Requirements

- Users can create up to 2 databases
- Maximum 10 tables per database
- Maximum 1000 records per table
- Users can run CREATE, INSERT, UPDATE, DELETE and SELECT queries
- Admin can monitor storage usage
- Admin can delete user databases

## SQL Challenges Requirements

- Easy challenges
- Medium challenges
- Hard challenges
- Expert challenges
- Questions based on healthcare and banking datasets
- Users can submit queries and view results
- Track completed challenges
- Track difficulty-wise progress
- Show challenge statistics

## Challenge Support Requirements

- Show hints
- Show multiple hints
- Show complete solution
- Explain the solution

## Discussion Requirements

- Users can discuss challenge solutions
- Users can ask questions
- Users can post optimization ideas

## Database Requirements

### Healthcare

- Patients
- Doctors
- Appointments
- Prescriptions
- Hospitals
- Billing

### Banking

- Customers
- Accounts
- Transactions
- Loans
- Credit cards

## Navigation

- Home page
- Tutorial page
- Playground page
- Database explorer
- Challenge page
- Admin dashboard

## Future Scope

- AI hints
- Query optimization suggestions
- More databases (Insurance, E-commerce)
- User profiles and progress tracking
- Interview preparation section

## Non-Functional Requirements

- Fast page loading
- Mobile-friendly UI
- Dark and light themes
- Secure query execution
- Responsive design
- Good user experience
