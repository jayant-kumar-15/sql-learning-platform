SELECT Statement

The SELECT statement is used to retrieve data from one or more tables.

Syntax


SELECT column1, column2
FROM table_name
WHERE condition;

Example


SELECT patient_name, age
FROM patients
WHERE age > 30;

Output

Name Age
John 35
Emma 42

Practice Question

Find all patients older than 40 years.
