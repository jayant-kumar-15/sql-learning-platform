         SQL LEARNING PLATFORM
         ============================================================

         FILE
         ----
         frontend/playground/playground.html

         PURPOSE
         -------
         Read-only SQL practice environment.

         PLAYGROUND RULE
         ---------------
         Users can execute SQL against the platform's predefined
         Healthcare and Banking learning databases.

         Unlike Sandbox:
         - Users cannot create databases here.
         - Users cannot create tables here.
         - Users cannot alter tables here.
         - Users cannot insert/update/delete permanent data here.
         - Databases and tables are provided for SQL practice.

         MAIN FEATURES
         -------------
         1. Database Explorer
         2. Healthcare / Banking learning databases
         3. Database table selection
         4. Active database indicator
         5. USE database_name support
         6. Multiple query worksheets
         7. Query rename
         8. Query close
         9. Persistent query tabs
         10. SQL execution
         11. Multiple SQL statements
         12. Selected-statement execution
         13. Describe table
         14. Schema viewer
         15. Relationship/data-model viewer
         16. Query results
         17. Result resize
         18. Result minimize
         19. Result maximize
         20. Result close
         21. CSV download
         22. Responsive/mobile layout

         IMPORTANT
         ---------
         This HTML only defines the UI.

         SQL execution logic belongs to:
         frontend/services/browserSqlEngine.js
         frontend/services/sqlEngine.js

         Query/result helper logic belongs to:
         frontend/js/queryApi.js
         frontend/js/queryResults.js

         ============================================================ -->
